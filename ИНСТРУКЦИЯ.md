# Склад Сканер — Инструкция по установке

## Что это

PWA-приложение (работает как обычный сайт, но можно «установить» на телефон) для сканирования штрих-кодов товаров на складе. Загружаете Excel-файл с листом отбора — приложение показывает таблицу товаров. Сканируете штрих-код на товаре — приложение находит его в таблице и отмечает зелёным.

---

## Часть 1: Размещение на GitHub Pages

### Шаг 1 — Создать репозиторий

1. Зайдите на [github.com](https://github.com) (создайте аккаунт, если нет)
2. Нажмите **«+» → New repository**
3. Название: `warehouse-scanner` (или любое другое)
4. Поставьте **Public**
5. Нажмите **Create repository**

### Шаг 2 — Загрузить файлы

1. В новом репозитории нажмите **"uploading an existing file"**
2. Перетащите ВСЕ файлы из папки `warehouse-scanner`:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon.svg`
   - `icon-192.png`
   - `icon-512.png`
3. Нажмите **Commit changes**

> ⚠️ Файлы `google-apps-script.js` и `ИНСТРУКЦИЯ.md` загружать НЕ нужно — они только для вас.

### Шаг 3 — Включить GitHub Pages

1. Перейдите в **Settings** репозитория (вкладка сверху)
2. В меню слева выберите **Pages**
3. В разделе **Source** выберите **Deploy from a branch**
4. Branch: **main**, папка: **/ (root)**
5. Нажмите **Save**

### Шаг 4 — Готово!

Через 1–2 минуты ваш сайт будет доступен по адресу:

```
https://ВАШ_ЛОГИН.github.io/warehouse-scanner/
```

Откройте эту ссылку на телефоне — и можно работать!

### Установка на телефон как «приложение»

**iPhone (Safari):**
1. Откройте ссылку в Safari
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой)
3. Выберите «На экран "Домой"»

**Android (Chrome):**
1. Откройте ссылку в Chrome
2. Появится предложение «Установить приложение» — нажмите
3. Или: меню (три точки) → «Установить приложение»

## Часть 2: Настройка Google Таблиц (по желанию)

Эта часть нужна, чтобы все сканирования автоматически записывались в Google Таблицу — можно отслеживать, кто что отсканировал с разных устройств.

### Шаг 1 — Создать Google Apps Script

1. Откройте [script.google.com](https://script.google.com)
2. Нажмите **«Новый проект»**
3. Удалите весь код из редактора
4. Откройте файл `google-apps-script.js` из папки и скопируйте весь код
5. Вставьте код в редактор
6. **(Опционально)** Если хотите писать в конкретную таблицу:
   - Создайте Google Таблицу
   - Скопируйте её ID из URL (часть между `/d/` и `/edit`)
   - Вставьте ID в строку `const SPREADSHEET_ID = '';`
   - Если оставить пустым — таблица создастся автоматически

### Шаг 2 — Опубликовать скрипт

1. Нажмите **«Развернуть» → «Новое развёртывание»**
2. Нажмите шестерёнку → выберите **«Веб-приложение»**
3. Описание: `Склад Сканер`
4. **Выполнять от имени:** `Меня`
5. **Доступ:** `Все` (чтобы приложение могло отправлять данные)
6. Нажмите **«Развернуть»**
7. Подтвердите доступ (Google покажет предупреждение — нажмите «Дополнительно» → «Перейти к...»)
8. **Скопируйте URL** вида `https://script.google.com/macros/s/.../exec`

### Шаг 3 — Вставить URL в приложение

1. Откройте «Склад Сканер» на телефоне
2. Нажмите ⚙️ (настройки)
3. В поле **«URL Google Apps Script»** вставьте скопированный URL
4. Укажите **имя устройства** (например: «Телефон Петрова»)
5. Нажмите **«Сохранить»**

Теперь каждое сканирование будет автоматически записываться в Google Таблицу!

## Как пользоваться

1. **Загрузите Excel-файл** — нажмите на область загрузки и выберите файл листа отбора
2. Появится таблица со всеми товарами
3. **Нажмите «Сканировать»** — откроется камера
4. Наведите камеру на штрих-код товара
5. При успешном сканировании:
   - **Зелёная** полоса — товар найден, звуковой сигнал ✓
   - **Красная** полоса — товар НЕ в заявке, звуковой сигнал ✗
   - Повторное сканирование — два коротких гудка ⚠️
6. Прогресс виден в статистике вверху (Собрано / Осталось)
7. Вкладка **«История»** — все сканирования за сессию

### Важно знать

- **Данные сохраняются** даже после закрытия браузера или перезагрузки
- Можно загружать разные таблицы — каждая хранится отдельно
- При работе нескольких человек — каждый указывает своё имя устройства в настройках
- Экспорт истории сканирований — кнопка 📤 в правом верхнем углу
